# Rumbo Colombia — actualización visual

## Cambios realizados
- Renovación de la paleta a azul océano, turquesa y dorado.
- Tipografía DM Sans para lectura y Manrope para títulos.
- Barra de navegación con degradado, botones con mejor jerarquía visual y estados de foco visibles.
- Hero principal actualizado con una fotografía panorámica creada para Rumbo Colombia.
- Fotografías de alta resolución para las tarjetas de destinos; Eje Cafetero usa una imagen local de cafetales y finca tradicional.
- Se conservaron las rutas, componentes, autenticación, perfil, reservas y panel administrativo existentes.

## Ejecutar el proyecto
1. Abre esta carpeta en Visual Studio Code.
2. Ejecuta `npm install` para instalar las dependencias en tu equipo.
3. Ejecuta `npm run dev`.
4. Abre la dirección local que muestre Vite en la terminal.

**Importante:** no se incluye `node_modules`; es preferible instalar las dependencias en el sistema donde se ejecutará el proyecto. El archivo `package-lock.json` se conserva.
